# Data Modelling

Data Modelling covers all structural and schema-level operations in Zoho Analytics — defining how data is stored, shaped, and related across tables. Use operations in this module when you need to work with tables, their columns, relationships between tables, or derived fields (formulas).

## Sub-areas

### 1. Table Operations

Creating tables, adding columns, and inspecting table schema.

→ Load [data_modelling_tables.md](./data_modelling_tables.md) for tool usage.

### 2. Query Tables

Query tables are SQL-based materialized views built on top of base tables in the same workspace. They allow you to pre-join, filter, or aggregate data into reusable named views.

→ Load [data_modelling_query_tables.md](./data_modelling_query_tables.md) for tool usage.

### 3. Relationships (Lookups)

Lookups connect a column in one table to a matching column in another, enabling multi-table reporting and formulas.

→ Load [data_modelling_lookups.md](./data_modelling_lookups.md) for tool usage.

### 4. Formulas & Derived Columns

Aggregate formulas (KPI measures) and custom formula columns (row-level computed fields) extend table data without modifying raw records.

→ Load [data_modelling_formulas.md](./data_modelling_formulas.md) for tool usage.
