# Data Management

Data Management operations cover reading from and writing to the actual data rows within tables in Zoho Analytics.

Use this module when the task is about the **contents** of a table — querying, exporting, importing, or mutating rows — rather than the table's structure (use Data Modelling for schema changes).

## Sub-areas

### 1. Read & Export

Retrieving data or exporting a view to a file.

Covers:
- Running a SQL SELECT query to retrieve records or gather insights
- Exporting a table, report, or query table to a CSV file
- Bulk-importing rows from a JSON array or a local CSV/JSON file

→ Load [data_management_read.md](./data_management_read.md) for tool usage.

### 2. Row-Level Writes

Adding, updating, or deleting individual rows in a table.

Covers:
- Inserting a single new row into a table
- Updating existing rows that match a criteria
- Deleting rows that match a criteria

→ Load [data_management_write.md](./data_management_write.md) for tool usage.
